# Painel do Claude — skill da Alexa

Skill pessoal que abre o painel de consumo do Claude no navegador do Echo Show.

Importar: Alexa Developer Console → Create Skill → Portuguese (BR) → Other → Custom → Alexa-hosted (Node.js) → **Import skill** → cole a URL deste repositório (terminando em .git).

Depois: aba **Test** → **Development**, e diga "Alexa, abrir painel do Claude".
